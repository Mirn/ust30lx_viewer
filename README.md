# UST-30LX Rust polar viewer

Минимальный viewer для Hokuyo UST-30LX по Ethernet/SCIP 2.2.

По умолчанию подключается к:

- IP: `192.168.0.10`
- TCP port: `10940`
- continuous command: `MD0000108001000`
- диапазон шагов: `0..1080` (270°)
- front step: `540`
- угловой шаг: `0.25°`
- отображаемая дальность: `0..2.0 m`

Программа использует бесконечный `MD`-stream (`number of scans = 00`) и автоматически переподключается через 1 секунду при обрыве TCP или таймауте.

## Запуск

Нужен обычный Rust stable (`rustup`/`cargo`).

```powershell
cargo run --release
```

Если адрес сенсора другой, его можно передать первым аргументом:

```powershell
cargo run --release -- 192.168.0.10:10940
```

## Управление

- `M` — зеркально перевернуть left/right. Полезно, если ориентация установленного лидара относительно экрана обратная.
- `Esc` — выход.

Окно resizable: размер полярной сетки пересчитывается каждый кадр через `screen_width()` / `screen_height()`, поэтому отдельной обработки resize не требуется.

## Что делает SCIP parser

Для каждого continuous frame ожидается:

1. echo `MD...`
2. status `99 + checksum`
3. 4-byte timestamp + checksum
4. строки данных, каждая с checksum

Checksum каждой строки проверяется. После удаления line checksum payload всех строк склеивается, потому что 3-byte distance value может быть разрезан границей строки SCIP. Затем каждые 3 байта декодируются как три 6-bit символа.

Для полного UST-30LX scan ожидается ровно 1081 расстояние.
